# Squeeze & Hold

**Skill:** squeeze (graded grip force). One-handed.

The child squeezes the grip and tries to keep the squeeze level inside a
target band (40-70% of a full squeeze) for 30 seconds.

- +10 points per second spent inside the band, counted in 100 ms steps.
- Leaving the band only ends the current hold. Points already earned stay.
- A soft `tick` haptic marks each full second of one continuous hold.
- Stars: 50 / 120 / 200 points.
- Metrics: `longestHoldMs`, `inBandMs`.
